
# Wallet Intelligence Platform

A blockchain analytics project for analyzing Ethereum wallet activity, transaction behavior, and on-chain insights using DuneSQL.

## Project Goal

Build a professional wallet analytics platform capable of analyzing any Ethereum wallet and providing insights into:

- Wallet activity
- ETH flows
- Token holdings
- DeFi interactions
- Wallet behavior
- On-chain intelligence

## Tech Stack

- Dune Analytics
- DuneSQL
- SQL
- GitHub
